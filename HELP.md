# Adding More Vocabulary

Spanish Vocab Widget includes 100 starter words and phrases. You can add your
own vocabulary or replace the starter list with a CSV file.

## Get more words

You can create a list in Numbers, Excel, Google Sheets, or another spreadsheet
app, then export or download it as a CSV file. You can also ask a language
teacher or a language-learning service to prepare a CSV using the format below.

Favor natural Mexican Spanish when creating new entries. Review generated or
downloaded vocabulary before importing it, especially accents, regional terms,
and translations.

## Required CSV columns

The first row must contain these column names:

Spanish,English

Example:

Spanish,English
hola,hello
gracias,thank you
¿Dónde está el baño?,Where is the bathroom?

The optional columns are Room, Category, Pronunciation, and Notes. Column names
are not case-sensitive. Save the file with the .csv extension.

## Import the CSV

1. Select the book icon in the Mac menu bar.
2. Select Import Vocabulary CSV.
3. Choose your CSV file.
4. Select Import.

Importing replaces the active vocabulary list. Keep a backup of any list you
want to retain. The imported list is stored at:

~/Documents/Spanish Vocab Widget/Vocabulary.csv

You may select Open Vocabulary File from the app menu to view or edit the
active file. After editing it, save the file and select Reload Vocabulary.

App updates do not replace the active vocabulary file.
